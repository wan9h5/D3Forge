## 本次修复

1. 曼哈顿 CSV 列顺序变化时，可能把 P-value 误当位置字段；加入位置字段别名识别并排除 P-value。
2. iframe 首次渲染时 SVG 文字宽度可能为零，导致图例重叠；加入支持中英文名称的宽度回退。
3. 新图形 Tooltip 在右侧 / 底部可能被裁切；增加宽度约束、长字符串折行与位置限制。
4. 数字染色体编号大于 25 时可能排在 X / Y 后面；改为先排序所有数字编号，再排 X / Y / MT 与其他 contig。
5. 预览的 script 结束标记转义会改变混合大小写原始字符串；改为保留原始大小写。
6. CSV 文件读取失败可能产生未处理的异步错误；改为显示可操作的错误信息并保留现有数据。
7. 柱状图 / 折线图的少量链式源码排版调整为分行形式。

## 复现命令

```bash

npm run build
```

真实浏览器脚本不新增 npm 依赖，使用本机 Chromium / Edge 的 CDP 接口。请使用独立的测试浏览器配置目录，避免连接日常浏览器：

```powershell
$qaProfile = Join-Path $env:TEMP ('d3forge-qa-' + [guid]::NewGuid().ToString('N'))
Start-Process -FilePath 'C:\Program Files (x86)\Microsoft\Edge\Application\msedge.exe' -WindowStyle Hidden -ArgumentList @('--headless=new', '--no-first-run', '--remote-debugging-port=9237', ('--user-data-dir=' + $qaProfile), 'about:blank')
```

启动开发服务后执行：

```bash
node scripts/browser-regression.mjs http://localhost:4173 9237
```

构建后在另一终端启动 `npm run preview -- --port 4174`，再执行：

```bash
node scripts/browser-regression.mjs http://localhost:4174 9237
```

脚本会把截图、CSV 测试文件、导出的 JS 和 JSON 结果保存在独立的系统临时目录，并打印路径。
