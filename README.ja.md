## D3Forge について

D3Forge は、フロントエンドだけで動作する D3.js のビジュアルコード作成ツールです。グラフを選び、サンプルデータやローカル CSV で見た目を調整して、完全なソースコードを自分のプロジェクトへ持ち帰れます。

**よく使う設定は準備済み。その先は自由にカスタマイズ。** 各グラフは実用的な基本設定で開きます。その他の適用可能な設定は詳細設定にまとめ、初期状態では無効にしています。必要な項目だけを有効にして調整できます。グラフごとに専用の設定を用意し、実際の利用場面やコミュニティの貢献をもとに拡充します。変更は対応するネイティブ D3 コードへ即座に反映されます。

デスクトップの作業画面は **設定 → リアルタイムプレビュー → 読み取り専用ソース** の3列構成です。プレビューは生成されたソースそのものを実行します。書き出したコードの依存先は D3 と DOM API のみで、別の Web プロジェクトでも動作します。

## D3Forge の発想：データからネイティブ D3 へ

D3Forge のアイデアは2つのきっかけから生まれました。まず、上司が D3 を気に入り、「とても面白いツールを作れる」と考えて、私に D3 を学ぶよう勧めてくれました。学ぶうちに、API が多くて覚えきれず、簡単なグラフでもかなりのコードが必要だと感じました。そこで、グラフのコードは2つの層で理解できると気づきました。**データ層**はフィールドを割り当てて位置を計算し、**表示設定層**はグラフの見た目を決めます。D3 では、座標軸、グリッド、折れ線、ツールチップなどの視覚要素をさらに別々の層として重ねられます。この気づきから、視覚的に設定を試しながら、生成されたネイティブ D3 コードも確認して再利用できる D3Forge を作ろうと思いました。

<p align="center"><img src="docs/assets/d3forgeinfo.jpg" width="920" alt="D3Forge の折れ線グラフのレイヤー構造：座標軸・グリッド・折れ線・ツールチップの4層、データ処理と表示設定の分離" /></p>

折れ線グラフを例に、1つのグラフを4つの表示レイヤーに分けています。**座標軸**はデータ範囲・スケール・目盛りを計算し、軸線と文字を設定します。**グリッド**は同じスケールから位置を求め、色・線幅・破線を設定します。**折れ線**はフィールド割り当て・並べ替え・座標計算を行い、色・線幅・曲線・点を設定します。**ツールチップ**は操作に応じて現在の行を読み取り、値を整形し、ホバー動作と表示スタイルを設定します。

各レイヤーでデータ処理と表示設定を分離するため、データの意味を変えずに見た目を調整できます。また、グラフごとに意味のある設定だけを提示できます。今後の研究・生物情報学向けグラフも、この分離に沿ってコミュニティから拡張できます。

折れ線グラフは最も分かりやすい例です。データの割り当てや表示設定を変更すると、プレビューと対応するソース行が同時に更新されます。散布図、ボルケーノ、ヒートマップ、生存曲線、Circos、構成図にも同じ考え方を適用しています。

## 主な機能

- **グラフライブラリ** — グラフの種類別に閲覧でき、各サンプルに再現可能なデータを同梱。
- **検索とカテゴリ** — グラフ名または見た目のカテゴリで検索でき、中国語・英語・日本語の名称に対応。
- **必要なときだけ読み込み** — ビューポート付近のカードだけサムネイルを生成し、完成した SVG をキャッシュします。スクロールや絞り込みで残りを追加します。
- **画面上での設定** — 点のサイズ、不透明度、色、軸、グリッド、凡例、ツールチップを調整。
- **コードへの即時反映** — 設定変更と同時にグラフを更新し、対応するコード行を表示・強調。
- **ソース閲覧** — D3 ロジックとデータを別タブで表示。構文の色分け、折り返し、`Ctrl+F` 検索に対応。
- **完全な書き出し** — 描画ロジックと現在のデータを含む `.js` をコピーまたはダウンロード。
- **ローカル CSV** — ファイルをアップロードせず、ブラウザ内で解析、列の割り当て、データ確認。
- **3言語対応** — 中国語・英語・日本語を切り替え可能。選択を記憶し、生成コードのコメントも切り替え。
- **製品ホーム** — インタラクティブなデモ、クイックスタート、使い方の案内。

### 散布図の拡張と3D

統合分析、グループ別回帰、フォールドチェンジ、回帰式と R²、周辺分布、バブル行列、順位、密度、motif 結果、対応のある観測、連続配色、GSEA NES／FDR、相関係数、分類別／グラデーション3D散布図を用意しています。各サンプルに専用の列割り当てと設定があり、信頼帯、サイズの対応付け、点の枠線などは必要に応じて有効化できます。

散布図サンプルは6〜36件の再現可能なデータで設定効果を示します。ダウンロードにはデータ配列、描画、統計処理、操作ロジックを含みます。割り当てた列名を維持すればデータを置き換えられます。3D図は D3 と SVG で投影、奥行き順の描画、回転、ズームを実装し、追加の実行ライブラリは不要です。

- 数値散布図：数値2列。ラベル、カテゴリ、サイズ、連続色を追加可能。3Dでは数値をもう1列追加します。
- バブル行列：行カテゴリ、列カテゴリ、非負のサイズ、色用数値。重複座標は自動集計しません。
- 対応のある散布図：対象 ID、条件、数値、任意のコホート。同じコホート・対象・条件の重複観測は平均します。
- GSEA 組み合わせ図：経路名、NES、FDR（0〜1）。HOMER／motif 図は計算済みの有意性・エンリッチメント結果を受け取ります。

回帰は線形・二次モデルに対応します。任意の95%信頼帯は固定シードの200回のペア・ブートストラップによる平均曲線の点ごとの区間で、個別観測の予測区間ではありません。Pearson／Spearman の P 値は自動計算しません。Spearman の同順位には平均順位を使います。GSEA、HOMER、PCA などの上流解析はブラウザ内では実行しません。

### 生存曲線・Circos・染色体図

11の入口を追加しました。既存のマンハッタン図、円形ヒートマップ、2トラック円形棒グラフは再利用します。生存曲線・Circos・染色体をサイドバーに追加し、SNP LD はヒートマップに分類します。基本設定を用意し、リスク人数表・検定・注釈などは必要に応じて有効にできます。

| 図 | 既定の入力列 | 主な設定 |
| --- | --- | --- |
| Kaplan–Meier | `subject, time, event, group` | 90/95/99%信頼区間、打切り印、リスク人数表、log-rank |
| 探索的最適カットオフ | `subject, time, event, score` | 手動／中央値／最大 log-rank 探索、最小群割合 |
| 遺伝子注釈 Circos | `chromosome, length, position, end, gene, group` | 比例扇区、引き出し線、座標目盛、注釈数 |
| 融合遺伝子 Circos | `chromosome, length, position, targetChr, targetLength, targetPos, gene, group, weight` | リンク表示、支持強度による線幅と絞り込み |
| 受容体・リガンド Circos | `source, target, ligand, receptor, weight` | 有向帯、強度フィルター、矢印、細胞名 |
| SNP 連鎖不平衡 | `chromosome, snpA, position, snpB, targetPos, r2` | 染色体、色範囲、SNP名とLD値 |
| SNP 密度 | `chromosome, length, position` | 窓サイズ、件数／Mbあたり密度、向き、色尺度 |
| 染色体座位 | `chromosome, length, position, gene, group` | 点半径、縦横配置、トラック厚さ、注釈 |
| 染色体示意・ピーク／区間分布 | `chromosome, length, position, end, gene, group` | 区間色、共通物理尺度、向きと厚さ |
| セントロメア付き区間 | 区間列 + `centStart, centEnd` | セントロメア輪郭、片段、座標、アセンブリ説明 |

- **生存分析：** 1対象1行、時間は非負、`event=1`はイベント、`event=0`は右打切りです。IDは任意ですが、指定時の重複IDはすべて除外します。同時点のイベントと打切りは同じリスク集合を用い、イベントを先に計上します。KMは Greenwood log-log 区間を使用し、遅延登録・競合リスク・共変量調整は扱いません。
- **探索的閾値：** 異なるスコアの中点を探索し、各群2例以上と指定最小割合を要求します。候補数、未補正 P、Bonferroni 補正 P を表示します。`maxstat` 手法とは異なり、標本内の最適値は独立データでの検証が必要です。
- **座標：** 同一アセンブリの参照長と0-based半開区間 `[position,end)` を指定します。座位は `0–length`。長さ・セントロメアの矛盾と範囲外区間は除外します。例の長さは実在種を表さず、細胞遺伝学的バンド・融合・ピークを推定しません。
- **SNPと関連：** LD は計算済み `r²`／`|D′|`（0–1）を入力し、重複対は平均、位置矛盾は除外します。遺伝子型からは計算しません。密度は1行1座位、空窓はゼロ、末端窓は実長を使用します。受容体・リガンド図は正の入力強度を集計し、扇区は送受信合計を表します。
- **出力と言語：** 決定的なデータ、計算、配置、ツールチップを独立した D3 + DOM コードに含めます。列割り当てを変更しても視覚設定を保持し、UIと生成コメントは中文・英語・日本語に対応します。

### ヒートマップの拡張

クラスタリング、円形、行列、カレンダー、2指標三角、選択遺伝子、クラスター分割、臨床情報、行列注釈、推移、推移と経路、文字マーク、集計棒、左右比較、点と茎、シンボル、サンキーの17種類を追加しました。各図に適した列の対応と設定を用意し、基本設定は調整済み、詳細項目は必要に応じて有効化できます。

- **入力**：縦長の `sample, gene, value`。カレンダーは `date, value` と有効な `YYYY-MM-DD` 日付を使用します。追加列で注釈、第2指標、サイズ、重みを指定します。
- **クラスタリング**：ユークリッド、マンハッタン、`1 − Pearson` 距離と、平均・単・完全連結を選択し、クラスター数で分割します。共通観測のない枝は最後に連結し、定数ベクトルの相関は明示した規則を使用します。
- **標準化と欠損**：行／列の母標準偏差 Z スコアを使用し、定数はゼロ、欠損は空欄にします。重複座標は平均または合計、左右面板は群別に集計して共通色範囲で比較します。
- **複合表示**：カテゴリ／数値の注釈帯、2指標三角、行平均／合計棒、クラスター推移、流量を保存するサンキー帯を提供します。推移は列順を使い、欠損で線を切ります。矛盾する注釈は `mixed` と表示し、経路・マークは入力結果を使って富化解析や検定は実行しません。
- **出力**：計算・配置・操作を D3 + DOM の独立したソースに含めます。中国語・英語・日本語の説明とコードコメントが連動します。

### ボルケーノプロットの拡張

遺伝子注釈、グラデーション、遺伝子接続付き二面、VIP、双曲線しきい値、細胞クラスター、2色／4分類、marker 分面、環状クラスター、カテゴリ注釈、操作付き、3色の12サンプルを追加しています。専用設定、再現可能なデータ、3言語の説明を用意し、基本設定は準備済み、追加設定は必要に応じて有効化できます。

- 基本入力は `gene,log2FC,pvalue`。元または補正済み P 値を割り当て、軸に選択列名を表示します。サイズ用の非負 `VIP`、機能色用の `category`、グループ配置用の `cluster`／比較条件列を追加できます。重複記録は保持し、差次的解析や多重補正は行いません。
- 注釈は P 値順または指定リストで選び、上限、重なり回避、引き出し線を設定できます。二面図は比較条件と共通／独立範囲を選択し、両側で一意の同名遺伝子だけを接続します。
- 探索的な双曲線境界は `|x| > FC` かつ `−log10(P) > −log10(Pしきい値) + a / (|x| − FC)`。描画と分類に同じ式を使い、統計検定や FDR 制御を意味しません。
- クラスター図は内部の横位置で log2FC、縦位置で符号付き `−log10(P)` を示します。環状図は扇形内の角度で log2FC、基準円から内外への距離で符号付き有意性を示します。単一細胞解析自体は実行しません。
- VIP は最小面積を超える点の面積に比例します。連続色は有意性または数値列に対応し、カテゴリ色は条件を満たす点だけに適用します。
- 遺伝子検索、範囲選択数、クリックでの注釈固定をネイティブ D3／DOM コードに含めます。検索と選択は強調のみで、書き出すデータを絞り込み・変更しません。範囲選択とホバー・クリック・ズームはモードを分けて使います。

### 棒グラフとヒストグラムの拡張

最初の18サンプルでは、誤差棒、二重トラック円形、接続帯付き百分率、バタフライ、縦棒、極座標、グループ、ドット、積み上げ、横積み上げ、3D、下部接続、立体、双方向、横グループ、三角、軸省略棒グラフ、近似曲線付きヒストグラムに対応しています。小規模で再現可能なデータ、専用の列割り当て、中英日の設定とコードコメントを用意しています。

- カテゴリ棒グラフは `category,series,value` のロング形式。系列は省略可能で、重複は合計または平均します。双方向図は入力の符号を維持し、百分率・放射状の配置は非負値を必要とします。
- 誤差棒は反復観測から平均、標本 SD、SEM、Student t による平均の95%信頼区間を計算可能。`n < 2` では誤差を推定しません。集計済みデータは中心・下限・上限を割り当て、カテゴリと系列の組み合わせを一意にします。有意差検定は行いません。
- ヒストグラムは数値1列を使用。等幅ビンは度数・確率密度に対応し、正規近似・カーネル密度曲線も縦軸の単位に合わせます。正規近似は正規性検定ではありません。
- ドット棒は単位と列数を設定でき、端数は最後の点の面積で表します。百分率の接続帯は構成変化を示し、個体の移動を示しません。
- 二重トラック円形図は内外の系列と共通／独立範囲を選択できます。ゲノム座標は自動解析しません。3D棒は SVG の投影、奥行き順、回転、ズームで小規模カテゴリ行列を表示します。
- 軸の省略区間を明示し、区間内の値は中抜き点で示してツールチップに元の値を保持します。下部接続面と立体側面は装飾で、追加の量を表しません。

### 二軸、グループ積み上げ、棒の形状

さらに14サンプルとして、アイス型、鉛筆型、背景付きステム、上下、二軸棒＋折れ線、曲線接続百分率、2.5D台座、二軸棒、グループ積み上げ、積み上げ接続線、二軸GO、グループ極座標、積み上げ＋折れ線、遺伝子の増減表示を用意しています。既存の棒＋円、GSEA NES／FDR、極座標図も利用できます。

- 二軸は `category,value,secondary` を使用。左右の指標をそれぞれ集計し、独立したスケールで表示します。右軸はタイトル／単位、目盛り書式、表示範囲を設定可能。P 値変換は `0 < P ≤ 1` のみを受け付け、集計後に `−log10(P)` を計算します。集計値も有効範囲内である必要があります。GO の初期設定は最小 P 値で、そのカテゴリの最も有意な記録を示します。結合 P 値の計算やエンリッチメント検定ではありません。軸の色は対応指標を示し、異なる軸の棒の高さは直接比較できません。
- グループ積み上げは `category,cohort,series,value` を使用。カテゴリ内にコホートを並べ、その中で成分を積み上げます。欠損組み合わせはゼロ、重複は合計または平均。グループ極座標はカテゴリの扇形内に系列を並べ、共通の半径スケールを使います。
- 積み上げ接続は直線／曲線、境界線／帯を選べ、同じ成分の集計値の変化を示します。積み上げ＋折れ線は選択した傾向列をカテゴリ別に平均し、積み上げ合計と同じ数値軸を使います。単位が違う場合は二軸図を使ってください。
- 上下棒は選択した非負系列をゼロ線の上下に配置し、下側の目盛りは大きさを示します。遺伝子増減図は入力の正負を維持して方向別に配色し、差次的発現解析は行いません。
- アイスの棒、鉛筆の先端、背景参照、2.5D台座には専用設定があります。装飾は数値を表す先端位置を変えません。背景参照値はデータ範囲を制限しません。

### 構成図の入力

構成図は非負値のロング形式 CSV を受け取り、重複カテゴリを合計します。円・ワッフル図はカテゴリと値、円グラフ行列はさらに行・列グループ、二重円・補助棒付き円は親・子・値、円付き棒はサンプル・カテゴリ・値を使用します。実際の CSV 列名はデータ設定で割り当てられます。

比率はサンプルまたは行列セルごとに計算します。二重円の内側は全体に対する親の比率、外側の角度は親に対応し、外側の百分率はその親の中での比率です。ワッフルの単位表示は近似で、ツールチップには正確な値と比率を保持します。入力済みの集計を表示する機能で、生物学的分類の推定や有意差検定は行いません。

### スタイルを直接選択

ライブラリには **118のサンプル** があり、散布図、折れ線、棒、箱ひげ、バイオリン、円、ワッフル、ヒストグラム、ヒートマップ、ボルケーノ、マンハッタン、生存曲線、Circos、染色体別に整理しています。同じ種類の派生図をまとめ、ドーナツ、扇形、引き出し線付きなどもカードから直接開けます。

バイオリン系は `group,value` に加え、任意のサブグループ `sex`、ファセット `tissue`、注釈 `letter` を使用できます。列名は変更可能です。分割バイオリンにはちょうど2つのサブグループが必要です。ファセットは共通の数値範囲が初期設定で、独立範囲にも対応します。

棒・箱ひげ・バイオリン図は既存の文字注釈を読み込めます。バイオリン図には比較括弧と説明を手動追加できます。**統計検定や P 値は自動生成しません。サンプルの文字と比較文はデモ用です。**

## クイックスタート

ローカル開発には **Node.js 22.12以降または24** と npm を推奨します。

```bash
git clone https://github.com/wan9h5/D3Forge.git
cd D3Forge
npm ci
npm run dev
```

ターミナルに表示されるアドレスを開きます。通常は `http://localhost:4173` です。

1. グラフライブラリでグラフを選択します。
2. 左側で設定を調整するか、CSV を読み込んで列を割り当てます。
3. 中央でグラフ、右側で対応する D3 ソースを確認します。
4. 完全なコードをコピーするか、`.js` をダウンロードします。

### 書き出したソースを使う

D3 をインストールします。

```bash
npm install d3
```

JavaScript モジュールに対応するプロジェクトで、DOM の準備ができてからコードを実行します。既存の `#chart` を使い、なければ自動でコンテナを作成します。

```html
<div id="chart"></div>
```

現在のサンプルまたは CSV データも書き出されます。割り当てた列名を維持して `const data` を置き換えることもできます。

```js
const data = [
  { sample: 'S01', expressionA: 12, expressionB: 18, group: 'Control' },
  { sample: 'S02', expressionA: 24, expressionB: 31, group: 'Treatment' },
];
```

### ビルドと公開

```bash
npm run build
npm run preview
```

`dist/` を静的ホスティングへ配置できます。ページ遷移にはハッシュルーティングを使います。

このリポジトリには GitHub Pages の自動公開ワークフローが含まれています。初回はリポジトリの `Settings` → `Pages` → `Build and deployment` → `Source` で `GitHub Actions` を選び、`main` ブランチを GitHub にプッシュしてください。その後は `main` へのプッシュごとに自動でビルドと更新が行われます。公開先は <https://wan9h5.github.io/D3Forge/> です。

## データと現在の制限

- CSV はローカル処理で、上限は **10 MB／10,000行**。大きな SVG データでは操作速度に影響する場合があります。
- 空欄・無効数値は除外します。対数軸は正の値、ボルケーノ図は `0 < p ≤ 1` が必要です。
- 設定は再読み込み後に保持されません。グラフを切り替えると、そのグラフの初期データと設定へ戻ります。
- 設定変更でプレビューを再生成するため、ズーム位置もリセットされます。
- 棒グラフの重複カテゴリ／系列は標準で合計し、平均も選択できます。数値軸は線形でゼロを含みます。
- 折れ線の X は数値または時間の連番です。日付文字列は事前に数値へ変換してください。X 順で並べ替えます。
- バイオリンは線形軸と Epanechnikov カーネル密度推定を使い、帯域幅の倍率を調整できます。単一点・定数グループでは代替帯域幅を使います。形状はサンプル数と合わせて解釈してください。
- マンハッタンの位置は非負、P 値は `0 < p ≤ 1`。染色体の長さは入力内の最大位置によるもので、参照ゲノム全長ではありません。
- マンハッタンの標準しきい値 `5e-8` は変更可能。有意点のラベルは小さい P 値を優先し、数を制限できます。
- 基本凡例は1行。詳細凡例は折り返し、縦配置、位置、文字サイズ、表示数を設定できます。データ全体は保持されます。
- ソースは読み取り専用です。双方向編集、画像書き出し、コンポーネントコード生成には対応していません。

プレビューは同梱 D3 を制限付き iframe で実行し、外部 CDN は使いません。入力文字列はテキストノードとして表示し、埋め込むコードの script 終了タグをエスケープします。ギャラリーのサムネイルは同じ生成ソースを使い、付近のプレビューを最大2件ずつ実行した後、SVG を制限付きキャッシュへ保存して iframe を解放します。書き出したファイルを共有する前に、含まれるデータを公開してよいか確認してください。
