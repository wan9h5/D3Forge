## D3Forge について

D3Forge は、フロントエンドだけで動作する D3.js のビジュアルコード作成ツールです。グラフを選び、サンプルデータやローカル CSV で見た目を調整して、完全なソースコードを自分のプロジェクトへ持ち帰れます。

**よく使う設定は準備済み。その先は自由にカスタマイズ。** 各グラフは実用的な基本設定で開きます。その他の適用可能な設定は詳細設定にまとめ、初期状態では無効にしています。必要な項目だけを有効にして調整できます。グラフごとに専用の設定を用意し、実際の利用場面やコミュニティの貢献をもとに拡充します。変更は対応するネイティブ D3 コードへ即座に反映されます。

デスクトップの作業画面は **設定 → リアルタイムプレビュー → 読み取り専用ソース** の3列構成です。プレビューは生成されたソースそのものを実行します。書き出したコードの依存先は D3 と DOM API のみで、別の Web プロジェクトでも動作します。

## 主な機能

- **グラフライブラリ** — グラフの種類別に閲覧でき、各サンプルに再現可能なデータを同梱。
- **画面上での設定** — 点のサイズ、不透明度、色、軸、グリッド、凡例、ツールチップを調整。
- **コードへの即時反映** — 設定変更と同時にグラフを更新し、対応するコード行を表示・強調。
- **ソース閲覧** — D3 ロジックとデータを別タブで表示。構文の色分け、折り返し、`Ctrl+F` 検索に対応。
- **完全な書き出し** — 描画ロジックと現在のデータを含む `.js` をコピーまたはダウンロード。
- **ローカル CSV** — ファイルをアップロードせず、ブラウザ内で解析、列の割り当て、データ確認。
- **3言語対応** — 中国語・英語・日本語を切り替え可能。選択を記憶し、生成コードのコメントも切り替え。
- **製品ホーム** — インタラクティブなデモ、クイックスタート、使い方の案内。

### 対応グラフ

| グラフ | 用途 | 主な設定・機能 |
| --- | --- | --- |
| 散布図 | 2つの数値変数を比較 | グループ色、線形／対数軸、ラベル、ズーム・移動 |
| ボルケーノプロット | 効果量と有意性を表示 | `−log10(p)`、有意性による分類、しきい値線 |
| 箱ひげ図 | グループ間の分布を比較 | 四分位数、中央値、1.5 × IQR のひげ、外れ値 |
| 棒グラフ | カテゴリの値や構成を比較 | グループ／積み上げ、横／縦、正負の値、数値ラベル |
| 折れ線グラフ | 時間や順序に沿った変化を表示 | 複数系列、平滑曲線、点、面の塗り、線形／対数軸 |
| バイオリンプロット | グループ別の分布密度を比較 | 帯域幅、横向き／分割／半バイオリン／レインクラウド、サブグループ、ファセット、箱ひげ要約、ジッター付き観測点 |
| マンハッタンプロット | 染色体ごとの関連の有意性を表示 | 染色体順序、累積位置、交互配色、有意／示唆しきい値、注釈 |
| ヒートマップ | 行列の値を比較 | ロング形式、重複座標の平均／合計、連続色／ゼロ中心の発散色、数値凡例 |
| ヒストグラム | 変数の分布を確認 | 等幅ビン、度数／確率密度、最大値を最後のビンに含む |
| 円／ドーナツグラフ | カテゴリの構成を表示 | 円／ドーナツ／扇形、角度・角丸、引き出し線、中央テキスト |
| 円グラフ行列 | 行・列グループの構成を比較 | ロング形式、セル別比率、欠損組み合わせの空白、共通カテゴリ色 |
| 二重円グラフ | 2階層の分類関係を表示 | 親子データ、親の合計を自動計算、親に対応する子の角度、ドーナツ型 |
| ワッフルチャート | 等量単位で比率を表示 | 四角／円／人物アイコン、行列数、最大剰余法による配分、実際の比率の表示 |
| 補助棒付き円グラフ | 親カテゴリの内訳を確認 | 親の円、展開カテゴリの選択、子の棒、接続線 |
| 円グラフ付き棒グラフ | 合計と構成を同時に比較 | サンプルの合計棒、サンプル別円グラフ、個別の構成比 |

### 散布図の拡張と3D

統合分析、グループ別回帰、フォールドチェンジ、回帰式と R²、周辺分布、バブル行列、順位、密度、motif 結果、対応のある観測、連続配色、GSEA NES／FDR、相関係数、分類別／グラデーション3D散布図を用意しています。各サンプルに専用の列割り当てと設定があり、信頼帯、サイズの対応付け、点の枠線などは必要に応じて有効化できます。

散布図サンプルは6〜36件の再現可能なデータで設定効果を示します。ダウンロードにはデータ配列、描画、統計処理、操作ロジックを含みます。割り当てた列名を維持すればデータを置き換えられます。3D図は D3 と SVG で投影、奥行き順の描画、回転、ズームを実装し、追加の実行ライブラリは不要です。

- 数値散布図：数値2列。ラベル、カテゴリ、サイズ、連続色を追加可能。3Dでは数値をもう1列追加します。
- バブル行列：行カテゴリ、列カテゴリ、非負のサイズ、色用数値。重複座標は自動集計しません。
- 対応のある散布図：対象 ID、条件、数値、任意のコホート。同じコホート・対象・条件の重複観測は平均します。
- GSEA 組み合わせ図：経路名、NES、FDR（0〜1）。HOMER／motif 図は計算済みの有意性・エンリッチメント結果を受け取ります。

回帰は線形・二次モデルに対応します。任意の95%信頼帯は固定シードの200回のペア・ブートストラップによる平均曲線の点ごとの区間で、個別観測の予測区間ではありません。Pearson／Spearman の P 値は自動計算しません。Spearman の同順位には平均順位を使います。GSEA、HOMER、PCA などの上流解析はブラウザ内では実行しません。

### 棒グラフとヒストグラムの拡張

最初の18サンプルでは、誤差棒、二重トラック円形、接続帯付き百分率、バタフライ、縦棒、極座標、グループ、ドット、積み上げ、横積み上げ、3D、下部接続、立体、双方向、横グループ、三角、軸省略棒グラフ、近似曲線付きヒストグラムに対応しています。小規模で再現可能なデータ、専用の列割り当て、中英日の設定とコードコメントを用意しています。

- カテゴリ棒グラフは `category,series,value` のロング形式。系列は省略可能で、重複は合計または平均します。双方向図は入力の符号を維持し、百分率・放射状の配置は非負値を必要とします。
- 誤差棒は反復観測から平均、標本 SD、SEM、Student t による平均の95%信頼区間を計算可能。`n < 2` では誤差を推定しません。集計済みデータは中心・下限・上限を割り当て、カテゴリと系列の組み合わせを一意にします。有意差検定は行いません。
- ヒストグラムは数値1列を使用。等幅ビンは度数・確率密度に対応し、正規近似・カーネル密度曲線も縦軸の単位に合わせます。正規近似は正規性検定ではありません。
- ドット棒は単位と列数を設定でき、端数は最後の点の面積で表します。百分率の接続帯は構成変化を示し、個体の移動を示しません。
- 二重トラック円形図は内外の系列と共通／独立範囲を選択できます。ゲノム座標は自動解析しません。3D棒は SVG の投影、奥行き順、回転、ズームで小規模カテゴリ行列を表示します。
- 軸の省略区間を明示し、区間内の値は中抜き点で示してツールチップに元の値を保持します。下部接続面と立体側面は装飾で、追加の量を表しません。

### 二軸、グループ積み上げ、棒の形状

さらに14サンプルとして、アイス型、鉛筆型、背景付きステム、上下、二軸棒＋折れ線、曲線接続百分率、2.5D台座、二軸棒、グループ積み上げ、積み上げ接続線、二軸GO、グループ極座標、積み上げ＋折れ線、遺伝子の増減表示を用意しています。既存の棒＋円、GSEA NES／FDR、極座標図も利用できます。

- 二軸は `category,value,secondary` を使用。左右の指標をそれぞれ集計し、独立したスケールで表示します。右軸はタイトル／単位、目盛り書式、表示範囲を設定可能。P 値変換は `0 < P ≤ 1` のみを受け付け、集計後に `−log10(P)` を計算します。集計値も有効範囲内である必要があります。GO の初期設定は最小 P 値で、そのカテゴリの最も有意な記録を示します。結合 P 値の計算やエンリッチメント検定ではありません。軸の色は対応指標を示し、異なる軸の棒の高さは直接比較できません。
- グループ積み上げは `category,cohort,series,value` を使用。カテゴリ内にコホートを並べ、その中で成分を積み上げます。欠損組み合わせはゼロ、重複は合計または平均。グループ極座標はカテゴリの扇形内に系列を並べ、共通の半径スケールを使います。
- 積み上げ接続は直線／曲線、境界線／帯を選べ、同じ成分の集計値の変化を示します。積み上げ＋折れ線は選択した傾向列をカテゴリ別に平均し、積み上げ合計と同じ数値軸を使います。単位が違う場合は二軸図を使ってください。
- 上下棒は選択した非負系列をゼロ線の上下に配置し、下側の目盛りは大きさを示します。遺伝子増減図は入力の正負を維持して方向別に配色し、差次的発現解析は行いません。
- アイスの棒、鉛筆の先端、背景参照、2.5D台座には専用設定があります。装飾は数値を表す先端位置を変えません。背景参照値はデータ範囲を制限しません。

### 構成図の入力

構成図は非負値のロング形式 CSV を受け取り、重複カテゴリを合計します。円・ワッフル図はカテゴリと値、円グラフ行列はさらに行・列グループ、二重円・補助棒付き円は親・子・値、円付き棒はサンプル・カテゴリ・値を使用します。実際の CSV 列名はデータ設定で割り当てられます。

比率はサンプルまたは行列セルごとに計算します。二重円の内側は全体に対する親の比率、外側の角度は親に対応し、外側の百分率はその親の中での比率です。ワッフルの単位表示は近似で、ツールチップには正確な値と比率を保持します。入力済みの集計を表示する機能で、生物学的分類の推定や有意差検定は行いません。

### スタイルを直接選択

ライブラリには **78のサンプル** があり、散布図、折れ線、棒、箱ひげ、バイオリン、円、ワッフル、ヒストグラム、ヒートマップ、ボルケーノ、マンハッタン別に整理しています。同じ種類の派生図をまとめ、ドーナツ、扇形、引き出し線付きなどもカードから直接開けます。

バイオリン系は `group,value` に加え、任意のサブグループ `sex`、ファセット `tissue`、注釈 `letter` を使用できます。列名は変更可能です。分割バイオリンにはちょうど2つのサブグループが必要です。ファセットは共通の数値範囲が初期設定で、独立範囲にも対応します。

棒・箱ひげ・バイオリン図は既存の文字注釈を読み込めます。バイオリン図には比較括弧と説明を手動追加できます。**統計検定や P 値は自動生成しません。サンプルの文字と比較文はデモ用です。**

## クイックスタート

ローカル開発には **Node.js 22.12以降または24** と npm を推奨します。

```bash
git clone https://github.com/wan9h5/D3Forge.git
cd D3Forge
npm ci
npm run dev
```

ターミナルに表示されるアドレスを開きます。通常は `http://localhost:4173` です。

1. グラフライブラリでグラフを選択します。
2. 左側で設定を調整するか、CSV を読み込んで列を割り当てます。
3. 中央でグラフ、右側で対応する D3 ソースを確認します。
4. 完全なコードをコピーするか、`.js` をダウンロードします。

### 書き出したソースを使う

D3 をインストールします。

```bash
npm install d3
```

JavaScript モジュールに対応するプロジェクトで、DOM の準備ができてからコードを実行します。既存の `#chart` を使い、なければ自動でコンテナを作成します。

```html
<div id="chart"></div>
```

現在のサンプルまたは CSV データも書き出されます。割り当てた列名を維持して `const data` を置き換えることもできます。

```js
const data = [
  { sample: 'S01', expressionA: 12, expressionB: 18, group: 'Control' },
  { sample: 'S02', expressionA: 24, expressionB: 31, group: 'Treatment' },
];
```

### ビルドと公開

```bash
npm run build
npm run preview
```

`dist/` を静的ホスティングへ配置できます。ページ遷移にはハッシュルーティングを使います。

## データと現在の制限

- CSV はローカル処理で、上限は **10 MB／10,000行**。大きな SVG データでは操作速度に影響する場合があります。
- 空欄・無効数値は除外します。対数軸は正の値、ボルケーノ図は `0 < p ≤ 1` が必要です。
- 設定は再読み込み後に保持されません。グラフを切り替えると、そのグラフの初期データと設定へ戻ります。
- 設定変更でプレビューを再生成するため、ズーム位置もリセットされます。
- 棒グラフの重複カテゴリ／系列は標準で合計し、平均も選択できます。数値軸は線形でゼロを含みます。
- 折れ線の X は数値または時間の連番です。日付文字列は事前に数値へ変換してください。X 順で並べ替えます。
- バイオリンは線形軸と Epanechnikov カーネル密度推定を使い、帯域幅の倍率を調整できます。単一点・定数グループでは代替帯域幅を使います。形状はサンプル数と合わせて解釈してください。
- マンハッタンの位置は非負、P 値は `0 < p ≤ 1`。染色体の長さは入力内の最大位置によるもので、参照ゲノム全長ではありません。
- マンハッタンの標準しきい値 `5e-8` は変更可能。有意点のラベルは小さい P 値を優先し、数を制限できます。
- 基本凡例は1行。詳細凡例は折り返し、縦配置、位置、文字サイズ、表示数を設定できます。データ全体は保持されます。
- ソースは読み取り専用です。双方向編集、画像書き出し、コンポーネントコード生成には対応していません。

プレビューは同梱 D3 を制限付き iframe で実行し、外部 CDN は使いません。入力文字列はテキストノードとして表示し、埋め込むコードの script 終了タグをエスケープします。書き出したファイルを共有する前に、含まれるデータを公開してよいか確認してください。

## 任意の詳細設定

基本設定に加え、グラフに適した軸、表示範囲、グリッド、ラベル、凡例、参照線、背景、余白、専用スタイルを折りたたみ式の詳細設定で提供します。初期状態では無効です。数値の表示範囲は描画だけを切り取りますが、ヒストグラムのビン範囲は観測を絞り込み、密度を再正規化します。
