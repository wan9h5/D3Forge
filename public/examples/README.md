# UCI Wine PCA example

Aeberhard, S. & Forina, M. (1992). *Wine*. UCI Machine Learning Repository.
https://doi.org/10.24432/C5PC7J — CC BY 4.0.

`wine.data` is the original 178-row, 13-feature dataset (first column is class).
Classes retain their source IDs; no cultivar names are inferred.

`wine-pca.csv` is a derived example generated by `scripts/prepare-pca-wine.py`:

- Center every feature and divide by its sample standard deviation (denominator n−1).
- Calculate the SVD of the standardized matrix Z; scores are ZV.
- Correlation loadings are V√λ. The same display multiplier scales both arrow components.
- PC1/PC2/PC3 explain 36.1988481%, 19.2074903%, and 11.1236305%.
- Fix component signs by making the largest-magnitude eigenvector entry positive.
- The CSV contains 178 `sample` rows and 13 `loading` rows; PC1/PC2/PC3 share columns.

The app displays group dispersion ellipses derived from sample covariance. These
are not confidence regions. It does not fit PCA to imported raw expression matrices.
